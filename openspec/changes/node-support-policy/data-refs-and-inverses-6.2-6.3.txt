## 6.3 — Every operation has an inverse

| Operation | Inverse | Shipped? | Reason |
|---|---|---|---|
| The probe cache's write (`pm-isolation-flag`) | `rm -f` of it on every hook run | **SHIPPED** (1.4, `b7ba061`; proven 1.5) | an untracked file whose writer is gone reads as a live mechanism |
| The shim's `mkdtempSync` (`pm-assert-no-git-*`) | `removeTempDir(shimDir)` in its exit listener | **SHIPPED** (2.4, `93e25e2`) | one directory per process under per-file isolation |
| The harness's `mkdtempSync` (`pm-empty-cache-*`) | `removeAtExit()` → `removeTempDir()` | **SHIPPED** (2.4b, `cb946eb`) | same leak, second site (Gate 1 I6) |
| `removeAtExit(dir)` (schedule) | none — a scheduled removal is not unscheduled | not shipped | nothing in the suite needs to keep a per-process temp dir past exit; an unschedule would only ever be used to leak |
| Raising the support floor | lowering it | **NOT shipped** | the policy only moves the floor up; a lowered floor would claim support for an end-of-life Node |
| Emitting the below-floor warning | suppressing it | **NOT shipped** | one line, only below the floor; the remedy is upgrading Node, and a switch to hide it would hide an end-of-life runtime |
| A matrix major added | a matrix major removed | **BOTH computed** | the same schedule filter (`supportedMajors`) adds a line when its `start` passes and drops it when its `end` does |
| `spawnAll`'s SIGKILL of a hung child | — | no inverse applies | a kill at the bound is terminal by design: the test fails naming the argv, and there is nothing to restore |
| The CI fallback taking over on a failed fetch | the computed set on the next successful fetch | **automatic** | `decide()` falls back only while the fetch fails; the next run with a working fetch computes and agreement-checks again |
