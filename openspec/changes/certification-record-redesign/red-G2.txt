## Residual loss — none, so the spec's four limits stand unchanged
Every recording site records BEFORE the operation it observes runs: the fs wrappers call pick() then the
original; the resolve hook records before the module loads; a spawn records (and writes its expectation)
before the child starts. Each event is one synchronous append through fs.writeSync captured at load. A
process killed at any instant has therefore lost at most the line for an operation it had not performed,
and only that last line can be torn; parseObservation() drops it and refuses any other corruption by name.
A process killed before its header or arrival line is written reports no arrival, which fails closed
("never loaded the observer"), not open.
