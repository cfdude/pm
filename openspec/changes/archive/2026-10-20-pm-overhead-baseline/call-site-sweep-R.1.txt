## Inverse enumeration
The verb is read-only and writes nothing (observe-by-fs-recorder test, assert/overhead.test.mjs 1.4 and 1.6): it adds no state, so there is no operation to undo. None owed.

## Findings
- Every hook verb hooks/hooks.json invokes (brief, snapshot, commit-nudge, gate-guard, lesson-advice) is a surface. Every rules heading resolves to exactly one feature in the table above.
- reviewMode, laneRouting and activityLog own no surface of their own (they change a value inside a core section, or a file nothing injects); the map test allows a feature with zero surfaces, so a future opt-in is not forced to state one. feature-switches-audit should read that as "no injected cost", not "unmeasured".
- hook:commit-nudge has no static size (see docs/measurement/2026-10-pm-overhead-baseline.md).
