G-M3 — the both-arms rationale was BACKWARDS. Measured on this machine's git 2.55.0, in a scratch
repository at .../g2fix-47/probe/a holding one TOP-LEVEL test file plus three under assert/ (one of
them two levels down):

  $ git ls-files 'scripts/test/*.test.mjs'
  scripts/test/assert/.hidden.test.mjs
  scripts/test/assert/sub/nested.test.mjs
  scripts/test/assert/visible.test.mjs
  scripts/test/top.test.mjs
  $ git ls-files 'scripts/test/**/*.test.mjs'
  scripts/test/assert/.hidden.test.mjs
  scripts/test/assert/sub/nested.test.mjs
  scripts/test/assert/visible.test.mjs          # top.test.mjs is MISSING

A git pathspec's `*` matches `/`, so the single-star arm reaches nested files too; it is the `**` arm
that misses the top-level file. The claims corrected said the opposite ("the nested arm is the only
one that reaches a file one level down", "one arm alone silently under-counts"), which would have led
the next reader to keep the WRONG arm. The pair is retained, now for the honest reason: the rule is
easy to re-read the other way — three documents in this change did — so naming both spellings makes
the enumeration correct under either reading. Fixed in design.md D5, proposal.md, drift.mjs's
trackedTestFiles and certification.mjs's enrolmentRefusals doc.
