* **A quoted free-text value that starts with `--` is no longer told to "quote the whole value" (#207).** `suggest-lane '--limit=5 ignored'` was refused with `If '--limit=5 ignored' is part of the text, quote the whole value`, but the value WAS quoted: the shell removed the quotes before the engine saw argv, so no amount of quoting helped. When the refused token holds whitespace (it reached the engine as one quoted value), the refusal now says so and names the way out: the `=` form where the verb has one (`suggest-lane --ask='--limit=5 ignored'`), otherwise to reword so the text does not start with `--` (`log-detour`, `honcho-memory`, `triage`, which have no `=` form). An unquoted flag-shaped word (`log-detour fixed --no-verify usage`) keeps the quoting hint, which is true for it. `triage` still has no `--ask=` form; that was not added.
