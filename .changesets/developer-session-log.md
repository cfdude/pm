* **New opt-in `set-dev-log on|off`: a developer-only session log (off by default, needs spend tracking).** `init` and
  `upgrade` never turn it on; `on` is refused while spend tracking is off and in a linked worktree or on a detached
  main HEAD, as `set-spend-tracking` is. `off` stops capture and deletes nothing. `upgrade` lists `devLog` among
  the opt-ins a repo has not adopted, and `overhead --all-features` counts it as on.
* **While the developer log and spend tracking are both on, `spend`'s ingest (and `spend-guard`'s, which shares it) appends a composition entry per assistant message to `.conductor/spend/devlog.jsonl`.** Each holds byte counts only (user text, tool results per tool name, attachments, an image count, the response's text and thinking bytes) and identifiers, never any text; tokens are joined from the ledger at report time. A `features` snapshot (each feature's on state and per-surface bytes from `overhead`) is appended when it changes. No hook reads or writes the file, and `spend --rebuild` does not duplicate entries.
* **New `dev-log [--session-id <id>] [--since <iso>] [--until <iso>] [--json] [--no-ingest]` verb and its inverse `dev-log --clear [--yes]`.** Reports, per Claude Code session, the message count, first and last time, the token classes and `work` (joined from the ledger by message id; a message whose row is gone reads `tokens: not in ledger`), the byte composition of requests and responses (labelled bytes, never converted to tokens), the features snapshot in force, and three retention warnings, each printed with its evidence and a threshold labelled a proposal: `stale-session` (first to last message at least 7 days), `large-context` (a message with at least 300,000 tokens of context) and `compacted` (the transcript recorded a compaction). With the log or spend tracking off it names the switch and the verb to run and opens nothing. `--clear` prints its plan first, `--yes` removes only `devlog.jsonl`, and it is refused while spend tracking is off. `--session-id` names a Claude Code transcript session, not pm's `--session` identity.
