* **The gate procedure gains an eighth required item: "Prove every guard can fail."** For each guard a change adds, the agent MUTATES it (removes or inverts the condition), confirms a test goes red, and saves the run as `mutation-evidence.txt` beside the change or plan; a SURVIVING mutant is a finding to fix, never a test to delete. The same item makes RED notes task-relative (`fails after 2.4`, never a bare "fails today") and has the agent re-run a RED note's assertion when the task that depends on it starts (#211). A new `mutation-pass` skill carries the method, the evidence-file shape and a worked example. Items 1-7 keep their numbers; run `/pm:upgrade` to refresh the block (about 560 bytes added to a fresh repo's rules block).
