* **A slow or unreadable `openspec --version` no longer reads as "no drift".** The installed OpenSpec version is now read from the `@fission-ai/openspec` package.json beside the resolved `openspec` binary on `PATH`, with no spawn; only when that cannot answer does the engine fall back to `openspec --version`, now with a 15 s timeout (was 3 s) and one answer per process. When the CLI is present but its version still cannot be read, the brief, `PROJECT.md` and `upgrade` print one fixed `OpenSpec drift UNKNOWN` line instead of nothing, so the drift line no longer appears and disappears between renders of the committed `PROJECT.md`. A CLI that is absent from `PATH` stays silent. (gh#196)
